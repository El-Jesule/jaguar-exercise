# Jaguar Habitat Atlas

A Spanish-language, single-page atlas of the jaguar in the Americas: an interactive map where each
of the 18 range countries reveals its population situation, plus curiosities, hunting behaviour,
habitual prey, a credited photo gallery, and a consolidated source list.

Live app entry: `src/main.tsx`. No backend, no database, no accounts, no analytics.

## Stack

- React 19 + TypeScript (strict) on Vite 7
- CSS Modules with design tokens in `src/app/app.css`
- Vitest + React Testing Library + jest-axe for unit, component, and a11y tests
- Playwright (Chromium, Firefox, WebKit) for end-to-end journeys
- ESLint (typescript-eslint typed rules) + Prettier

## Data integrity rules

The page is a curated publication, not a live data feed. Three rules are enforced by tests in
`src/content/content.test.ts` and `src/domain/invariants.ts`:

1. **Exactly 18 resident range countries** must exist, with the exact identifier set from
   `src/domain/types.ts`.
2. **No unsourced figures.** A country either has an estimate with a reference year and at least one
   source, or the explicit `kind: 'none'` state with a note naming the covering source. The
   "Sin estimación publicada" state must never be replaced by `0` or a placeholder.
3. **No orphan or dangling references.** Every referenced source exists and is referenced at least
   once; every habitat id resolves; every photo file exists on disk with alt text and dimensions.

Only Mexico publishes a national estimate used here (4,800 jaguars, CENJAGUAR 2018). The remaining
countries use the explicit no-estimate state with an explanatory note. No figure is derived,
interpolated, or summed from another.

## Map generation

`src/features/map/country-paths.ts` is generated, not hand-written:

```bash
node scripts/build-map.mjs
```

It reads `scripts/data/ne_110m_admin_0_countries.geojson` (Natural Earth 1:110m admin-0, public
domain), extracts the 18 range countries, splits French Guiana out of the France multipolygon,
simplifies the rings, projects them with Mercator, and emits SVG path data. The United States is
intentionally excluded from the map because it has no confirmed resident population (historical or
sporadic presence only).

## Photographs

`public/photos/*.webp` and `src/content/photos.ts` are generated by:

```bash
node scripts/fetch-photos.mjs
```

The script pulls a curated set from Wikimedia Commons, verifies the license, resizes to 1400 px,
encodes WebP, and records author, license, license URL, and intrinsic dimensions. Metadata is cached
in `scripts/data/photos-cache.json` so reruns are resumable.

## Accessibility

- Every country is reachable by keyboard, with a visible focus indicator and `aria-pressed` state.
- The country list mirrors the map with the same names and the same panel updates.
- Escape clears the selection and keeps focus where it was.
- Trend and status information are always conveyed as text, never colour alone.
- `prefers-reduced-motion` disables transitions.
- Automated `jest-axe` checks cover the page, the map, the open panel, the gallery, and the hunting
  section.
